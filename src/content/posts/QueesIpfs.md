## El sistema de archivos que quería salvar a la Web

---

## ✨ Introducción  
Internet fue diseñado para compartir conocimiento.  
Pero con el tiempo se transformó en algo muy distinto: plataformas centralizadas, servidores privados y empresas que controlan casi toda la información que vemos.

Cuando escribes una dirección web, en realidad estás preguntando:
> “¿Dónde está este archivo?”

IPFS propone una pregunta diferente:
> “¿Cuál es este archivo?”

Ese cambio, aparentemente pequeño, cambia toda la arquitectura de la web.

Esta es la historia del sistema de archivos que quiere construir una **Web permanente, distribuida y resistente a la censura**.

---

## 🌐 La Web basada en direcciones  
Hoy en día, Internet funciona de una forma muy concreta:

Cuando visitas una web, tu navegador busca una **dirección** (una IP o un dominio) que apunta a un servidor específico.  
Ese servidor envía los datos.

Esto genera varios problemas estructurales:

- Si el servidor cae, la web desaparece.  
- Si una empresa lo apaga, el contenido muere.  
- Si un gobierno lo bloquea, deja de existir.  
- Si el dueño cambia el archivo, la versión anterior se pierde.

La web moderna es frágil, incluso cuando parece enorme.


---

## 🧑‍🔬 El problema que nadie quería mirar  
Juan Benet, el creador de IPFS, se frustraba con algo muy concreto:  
Cada enlace en internet apuntaba a un lugar, no a un contenido.

Eso significaba que la memoria digital de la humanidad dependía de servidores privados.

Documentos, artículos científicos, vídeos, libros… todo podía desaparecer con un simple “404 Not Found”.

IPFS nació para responder a una pregunta radical:
> ¿Y si la web no dependiera de servidores, sino de las personas que guardan los archivos?

---

## 🧱 Qué es IPFS realmente  
IPFS significa **InterPlanetary File System**.

No es una blockchain.  
No es una criptomoneda.  
Es un **sistema de archivos distribuido**.

En IPFS:
- Los archivos no viven en un servidor.  
- Viven en miles de computadoras al mismo tiempo.  
- Se identifican por lo que contienen, no por dónde están.

Esto se llama **content addressing** (direccionamiento por contenido).


---

## 🔐 El poder del hash  
Cuando subes un archivo a IPFS, el sistema calcula un **hash criptográfico** de su contenido.

Ese hash:
- Es único para ese archivo.  
- Cambia si cambias una sola letra.  
- Funciona como su dirección permanente.

Ejemplo:
Si subes una imagen, IPFS la convierte en algo como:
QmXoY…a83k

Ese código es la identidad del archivo.

Cualquier persona del mundo que pida ese hash recibirá **exactamente ese contenido**, no una versión alterada.

---

## 🧩 Cómo se almacenan los archivos  
IPFS no guarda archivos completos como una sola pieza.  
Los divide en pequeños fragmentos llamados **bloques**.

Cada bloque:
- tiene su propio hash  
- puede almacenarse en distintas computadoras  
- se reutiliza si otro archivo contiene los mismos datos

Esto crea una red donde:
- los datos no se duplican innecesariamente  
- los archivos grandes se reconstruyen desde múltiples fuentes  
- la red es muy difícil de destruir


---

## 🌍 La web como una red de bibliotecas  
Imagina IPFS como una gigantesca red de bibliotecas.

Cuando alguien pide un libro:
- no importa de qué biblioteca venga  
- mientras tenga el mismo contenido

El archivo se descarga desde el nodo más cercano, más rápido o más disponible.

No existe un “servidor oficial”.

---

## 🧠 IPFS + Blockchain = Web3  
Las blockchains son muy malas guardando archivos grandes.  
Pero son excelentes guardando **referencias inmutables**.

Aquí es donde IPFS encaja perfectamente:
- La blockchain guarda el hash.  
- IPFS guarda el archivo.  

Así se construyen:
- NFTs  
- webs descentralizadas  
- metaversos  
- almacenamiento permanente  
- identidades digitales


---

## 🛡 IPFS contra la censura  
Si un gobierno quiere censurar una web tradicional:
- bloquea el dominio  
- apaga el servidor  

Con IPFS:
- no hay servidor central  
- no hay dominio que bloquear  
- los datos viven en miles de nodos

Mientras alguien en el mundo tenga el archivo, existe.

---

## 🧩 Conclusión  
IPFS no es solo una tecnología.  
Es una nueva filosofía para Internet.

Una web:
- donde los enlaces no se rompen  
- donde los archivos no desaparecen  
- donde nadie puede borrar la historia digital

Es la infraestructura de la Web3.

---

## 📌 Resumen final  

- IPFS es un sistema de archivos distribuido.  
- Los archivos se identifican por su hash.  
- No dependen de servidores.  
- Es resistente a censura y fallos.  
- Se integra con blockchain para crear Web3.
